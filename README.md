# 🔊 Text-to-Speech Converter

A simple and interactive **Text-to-Speech Converter** built using **HTML, CSS, and JavaScript**.
This project uses the browser's **Speech Synthesis API** to convert user-entered text into spoken audio instantly.

## ✨ Features

* 📝 Type any text
* 🔊 Convert text into speech instantly
* 🎨 Clean and responsive UI
* ⚡ Built using JavaScript Web Speech API
* 📱 Works directly in the browser

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* SpeechSynthesis Web API

## 📚 What I Learned

* DOM manipulation
* Event handling in JavaScript
* Using browser speech synthesis APIs
* Building interactive frontend projects
